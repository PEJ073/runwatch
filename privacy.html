Informativa sulla privacy di RunWatch

Ultimo aggiornamento: novembre 2026.

Dati raccolti

Durante una corsa l'app registra sull'orologio: posizione GPS, altitudine, orari, distanza e frequenza cardiaca. Non raccoglie nome, contatti o altri dati personali.

Dove vanno i dati

  • I dati restano sull'orologio finché non vengono caricati.
  • Ogni corsa viene caricata come file TCX esclusivamente nel Google Drive dell'utente stesso, in una cartella "RunWatch" creata dall'app.
  • L'app usa il permesso Google drive.file: accede solo ai file che crea, non legge né modifica altri file del Drive.
  • Solo se l'utente attiva l'opzione "Correggi su sentieri", le coordinate GPS della corsa vengono inviate al servizio pubblico di routing OpenStreetMap (routing.openstreetmap.de, gestito da FOSSGIS e.V.) per allinearle ai sentieri. Nessun altro dato viene inviato.

Condivisione

I dati non vengono venduti né condivisi con terze parti, non vengono usati per pubblicità e non sono accessibili allo sviluppatore.

Uso dei dati Google

L'uso delle informazioni ricevute dalle API Google rispetta le Google API Services User Data Policy, inclusi i requisiti di uso limitato (Limited Use).

Revoca e cancellazione

L'utente può revocare l'accesso in qualsiasi momento da myaccount.google.com/permissions e cancellare i file dalla cartella "RunWatch" del proprio Drive. Disinstallando l'app dall'orologio vengono cancellati anche i dati salvati sull'orologio.
